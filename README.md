# ตัวชี้วัดแผนปฏิบัติราชการ กรมทางหลวง 2566-2570

Dashboard ตัวชี้วัด 40 ตัวของยุทธศาสตร์ที่ 1-5 ผลรายปี 2566-2569 เทียบเป้า (ข้อมูล ณ 24 พ.ย. 2569)

- เปิด `index.html` ดูภาพรวมและหน้าแยกรายยุทธศาสตร์ (`#s1` ถึง `#s5`)
- กราฟใช้ไลบรารี d3 จาก cdnjs.cloudflare.com ต้องต่ออินเทอร์เน็ตจึงจะเห็นกราฟ

## ข้อควรระวัง

- รวบรวมจากรายงาน PG2 บทที่ 4 ไฟล์ผลตัวชี้วัดของหน่วยงาน และรายงานผลตัวชี้วัดปี 2568 ยังไม่ได้ตรวจซ้ำกับต้นฉบับทุกค่า
- แท่งกราฟสีจางขอบประคือค่าจากไฟล์หน่วยงานหรือที่คำนวณเอง ไม่ใช่ค่าตามรายงาน
- ตัวชี้วัดบางตัวยืนยันที่มาของตัวเลขไม่ได้ (เช่น P3.3) ดูหมายเหตุในการ์ด
